# Introduction

`rssdude` reads RSS feeds through a terminal UI or scripting commands. An optional HTTP server lets clients use a shared database.

The default database and configuration live under `~/.rssdude/`. Feed sync and full-article retrieval make network requests; configured server mode sends requests to that server. No hosted account is required for standalone mode, but this is not a claim that the program makes no network connections.
